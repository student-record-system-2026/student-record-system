# Sprint 1 — Requirement-to-Code Traceability

GitHub Issue → Requirement → Implemented functionality → Relevant files → Tests

Paths are relative to the repository root. `B` = `backend/src/`, `F` = `frontend/src/`.
Test IDs (TC-xx) are the Test Plan v1.1 §12 test cases; each automated test is named after the TC step it covers.

Layering (SADS §3.1): every feature goes **UI page → `api/client.js` → route (role gate) → controller (request validation) → service (business rules + record-level authorization) → repository (parameterized SQL) → PostgreSQL**. The table lists each layer's file for each issue.
